# LeakSanitizer suppressions for the TLS-refactor autest suite (BoringSSL build).
#
# Usage:
#   ASAN_OPTIONS="detect_leaks=1"
#   LSAN_OPTIONS="suppressions=<this file>:print_suppressions=1"
#   traffic_server -F           # freelist OFF: every alloc/free is a real malloc/free
#                               # (disables both the class FreelistAllocator and the
#                               #  per-thread ProxyAllocator cache; ink_queue.cc:133,
#                               #  ProxyAllocator.cc:33) so LSan sees genuine leaks.
#
# Each entry is a ONE-TIME or IN-FLIGHT/CONFIG-at-SHUTDOWN allocation: bounded (does
# NOT grow with steady-state traffic) and NOT introduced by the TLS refactor (every
# load-bearing line verified byte-identical to merge-base 09c4f8a12, the pre-refactor
# fork point, via git show/blame). autest stops traffic_server with SIGINT, whose
# handler does a FAST EXIT (shutdown_timeout=0): no config teardown, no connection
# drain. So loaded configs and any in-flight connection/transaction state are still
# owned at exit and reported by LSan. These are shutdown artifacts, not real leaks.
#
# CONTROL: the basic `tls` test (40 inbound TLS POSTs that COMPLETE before stop) leaks
# ZERO SSL/VC/session objects -> the normal per-connection path frees everything; only
# the entries below survive a forced fast-exit. The refactored SSLNetVConnection
# destructor (SSLNetVConnection.cc:1017, _ssl=nullptr -> SSL_free) is reached from every
# terminal path via free_thread and frees _ssl/BIOs/buffers/_unvc exactly once.
#
# Frames are chosen as narrowly as possible so a genuine growing/per-connection leak in
# the same subsystem stays visible. Bucket key:
#   A = one-time or in-flight-bounded shutdown artifact (non-refactor).
#   B = genuine PRE-EXISTING leak that grows; suppressed to keep the gate clean and
#       documented in tls_autest_LEAK_NOTES.md for a separate fix. (non-refactor)
#   C = refactor-introduced leak -> NONE FOUND (would NOT be suppressed).

# ============================ A: one-time startup / config ============================

# [A] Logging worker-thread continuations, allocated once in Log::create_threads via
#     Log::load_config(). init guarded by FULLY_INITIALIZED (set once, never cleared),
#     so it runs exactly once per process even across reloads. Process-lifetime
#     singletons with no free path by design. (src/proxy/logging/Log.cc; not refactored)
leak:Log::create_threads

# [A] Per-SNI / per-client SSL_CTX (+ its cert/key/CA sub-tree) cached in
#     SSLConfigParams::top_level_ctx_map at config load. Bounded by distinct cert
#     configs (<=4 observed); freed on reload via ~SSLConfigParams -> cleanupCTXTable ->
#     top_level_ctx_map.clear() (SSLConfig.cc:1097, driven by ConfigProcessor refcount
#     drain). Held by the live config at SIGINT fast-exit. (src/iocore/net/SSLConfig.cc)
leak:SSLConfigParams::getCTX

# [A] Inbound server SSL_CTX cert/chain loaded at config (ssl_multicert.config).
#     Config-load scoped only (never per-connection); bounded by cert count; held by
#     the live SSLCertLookup at fast-exit. (src/iocore/net/SSLUtils.cc)
#     NOTE: the EVP_PKEY private key on this same path is a real leak -> see [B] below.
leak:SSLMultiCertConfigLoader::load_certs

# [A] Continuations registered as GLOBAL hooks by the autest TEST plugins at
#     TSPluginInit (ssl_hook_test.cc / ssl_verify_test.cc / ssl_client_verify_test.cc).
#     Fixed count per plugin argv; test-only; symbol exists nowhere in src/. one-time.
leak:setup_callbacks

# ===================== A: in-flight connection/session state at SIGINT =================
# Bounded by the number of CONCURRENT connections at the instant of fast-exit, NOT by
# total traffic. A verified normal-close free path exists for each; HTTP/2 + ProxySession
# are entirely untouched by the TLS refactor (no http2/ file in the refactor diff).

# [A] Origin (server-side) HTTP/2 session parked idle in EThread::server_session_pool.
#     Freed on close via Http2ServerSession::destroy->free->common_free->THREAD_FREE
#     (Http2ServerSession.cc:44-67) and on pool purge. (proxy/http2; not refactored)
leak:Http2ServerSession::Http2ServerSession

# [A] SSLProxySession wrapper (unique_ptr ProxySession::_ssl) for an in-flight origin
#     session. Freed by ~ProxySession (_ssl.reset(), ProxySession.cc:47). The leak stack
#     only PASSES THROUGH the refactored SSL VC; alloc+owner+free diff vs merge-base is
#     empty. (src/proxy/ProxySession.cc; not refactored)
leak:ProxySession::_handle_if_ssl

# [A] ProxyMutex of an in-flight HTTP/2 stream open at shutdown. Released by ~Http2Stream
#     (Ptr<ProxyMutex>) via terminate_if_possible->THREAD_FREE. (proxy/http2; not refactored)
leak:Http2ConnectionState::create_stream

# [A] The OpenSSL SSL object + the layered rbio/wbio (BIO_MIOBuffer) for an in-flight
#     TLS connection. Sole alloc site; owned by unique_ptr<SSL,SSL_free> _ssl and freed
#     by ~SSLNetVConnection on normal close (calibration: 0 leaks when inbound completes).
#     Only in-flight (mostly outbound origin) handshakes at fast-exit survive.
leak:SSLNetVConnection::_make_ssl_connection

# [A] In-flight OUTBOUND origin connection SETUP state: the SSLNetVConnection allocated by
#     SSLNetProcessor::connect_re/allocate_vc, its _read_buf/_write_buf (unique_ptr members
#     freed by ~SSLNetVConnection on close) and the strdup'd NetVCOptions copy. Only the
#     origin connections still mid-setup at the SIGINT fast-exit survive; bounded by
#     concurrent origin connects. connect_re is the outbound-only SSL path (inbound uses
#     accept), so this cannot mask an inbound/per-conn VC leak. (src/iocore/net/SSLNetProcessor.cc)
leak:SSLNetProcessor::connect_re

# [A] All BoringSSL handshake-internal state for an in-flight OUTBOUND origin handshake
#     (server cert chain parse/verify, SSL_SESSION dup + its X509/ASN1 session cache,
#     TLS1.3 AEAD contexts, RSA verify scratch). All allocated under SSL_do_handshake
#     driven by _ssl_connect; freed by SSL_free when the VC closes. Bounded by concurrent
#     origin handshakes + the (LRU-capped, reload-freed) client SSL_CTX session cache.
leak:SSLNetVConnection::_ssl_connect

# ============== B: genuine PRE-EXISTING leaks (grow); suppressed + documented ==========
# Both verified byte-identical to merge-base (NOT refactor-introduced). See
# tls_autest_LEAK_NOTES.md for alloc site, root cause, and the proposed upstream fix.

# [B] EVP_PKEY (server private key) leaked once per key load: SSLPrivateKeyHandler
#     (SSLUtils.cc:934) never EVP_PKEY_free()s the caller's ref after a successful
#     SSL_CTX_use_PrivateKey. GROWS per config reload / per TSSslSecretSet.
leak:SSLPrivateKeyHandler

# [B] ConfigReloadProgress continuation (ConfigReloadTrace.cc:393) is `new`ed per
#     `traffic_ctl config reload` and never deleted, even on the normal EVENT_DONE
#     completion path. GROWS per reload. (mgmt/rpc; not refactored)
leak:ConfigReloadTask::start_progress_checker
